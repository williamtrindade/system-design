# System Design

This repository is dedicated to the study and documentation of large-scale software architecture. The main focus is exploring how to build distributed, resilient, and efficient systems.

## 📌 Repository Structure

To keep things simple and accessible, each architecture problem or case study is placed directly in the root directory. 

Each project space (e.g., `url-shortener`) contains its respective Excalidraw diagrams, markdown notes, and trade-off analyses regarding database strategies, caching, and scalability.

## 🚀 Case Studies

- [ ] **URL Shortener** (e.g., bit.ly)
- [ ] **News Feed System** (e.g., Instagram/Twitter)
- [ ] **Messaging System** (e.g., WhatsApp/Facebook Messenger)
- [ ] **Rate Limiter**
- [ ] **Video Distribution System** (e.g., YouTube/Netflix)
